VFEM.jl verification report

Interval Lehmann-Goerisch Verification Against A Closed-Form Spectrum

This report confirms the interval-mode Lehmann-Goerisch path currently implemented in VFEM.jl by comparing its certified two-sided result with the closed-form first Dirichlet Laplace eigenvalue on the unit-side equilateral triangle.

Scope Check

The implemented interval LG pipeline is the 2D pipeline: verified CR Liu shift, conforming P5 Galerkin eigenvector projector, interval P5 stiffness and mass matrices, verified RT5 H(div) auxiliary solve, and verified LG transform. This is the correct available implementation to confirm.

The 3D tetrahedron work currently has interval CR assembly and a verified discrete CR eigensolve. A full 3D LG method is not implemented yet because the repo does not yet contain the required 3D Lagrange eigensolver and 3D RT/H(div) auxiliary solver.
